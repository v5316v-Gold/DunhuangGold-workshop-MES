# ui_preview 手动 UI 测试 checklist

> **目标**:验证 32 个页面渲染、表单交互、页面间跳转衔接
>
> **测试人**:QA / 项目经理
>
> **环境**:Chrome / Edge / Firefox 最新版,打开 http://localhost:8080
>
> **流程**:每页检查渲染 + 数据 + 跳转;表单页检查提交 + 刷新数据
