## 📱 响应式断点

| 断点 | 宽度 | 行为 |
|------|------|------|
| **PDA** | ≤ 768px | 顶栏瘦身 + 侧栏转底部 Tab Bar(64px 高) + 表格横向滚动 + 弹窗全屏 |
| **Tablet** | 769-1279px | 间距压缩 + 字号缩小 + 侧栏 220px |
| **Desktop** | 1280-1919px | 默认布局(侧栏 260px) |
| **大屏** | ≥ 1920px | 扩宽到 300px 侧栏,字号 +20% |

## 🖱️ 触摸目标(车间手套优化)

| 类型 | 最小尺寸 | 适用 |
|------|----------|------|
| 全局最小 | **48×48 px** | 菜单项、按钮、tab |
| 主操作 | **56×56 px** | 报工提交、扫码、确认 |
| 危险操作 | **64×64 px** | 报废、删除、超耗 |
| 输入框 | min-height 48px | 戴手套点选 |

**额外**:`touch-action: manipulation` 禁止双击放大,`-webkit-tap-highlight-color: transparent` 去除蓝色高亮。

## 🔔 Toast 通知

```js
toast('success', '报工提交成功,损耗 0.070g');
toast('error',   '库存不足,无法领用');
toast('warning', '⚠ 即将超耗,请复核');
toast('info',    '当前页没有表单');
```

全局出现在右上角(顶栏下方),3 秒自动消失,带滑入动画。

## 🎯 焦点环(A11y)

所有交互元素:
- 鼠标点击:`outline: none`(不显)
- 键盘 Tab:`outline: 3px solid var(--gold)`(金色光环,清晰可见)

同时新增 `.skip-link`(按 Tab 第一个出现"跳转到主内容"链接,无障碍标准)。

---

## 📊 数据更新动画

新加 `.data-updated` 类:数据变化时给元素加 `animate-pulse-once` 动画(金色脉冲 1 秒),**操作员视线被吸引**,用于实时推送场景。

## 性能开销

- shortcuts.js 加载:13.7 KB(< 1 个图像大小)
- 启动开销:DOMContentLoaded 时绑定 keydown listener,常数时间
- 内存:无内存泄漏(全部用 addEventListener,无闭包陷阱)
- 命令面板:按需创建,关闭即销毁

**零影响核心业务**,纯增强层。
